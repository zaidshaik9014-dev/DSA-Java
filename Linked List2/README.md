# Linked List

This folder contains implementations and problems related to Linked Lists in Java.

---

## 🧠 What is a Linked List?

A Linked List is a linear data structure where elements (nodes) are connected using pointers instead of contiguous memory.

Each node contains:
- Data
- Reference (pointer) to the next node

## ⚙️ Time Complexity

| Operation            | Time Complexity |
|---------------------|----------------|
| Access (by index)   | O(n)           |
| Search              | O(n)           |
| Insertion (head)    | O(1)           |
| Insertion (end)     | O(n)           |
| Deletion (head)     | O(1)           |
| Deletion (end)      | O(n)           |
