# ArrayList

This folder contains problems and implementations using Java ArrayList.

---

## 🧠 What is ArrayList?

ArrayList is a dynamic array in Java that can grow or shrink in size automatically.

Unlike normal arrays:
- Size is flexible
- Provides built-in methods for easy manipulation

## ⚙️ Time Complexity

| Operation            | Time Complexity |
|---------------------|----------------|
| Access              | O(1)           |
| Search              | O(n)           |
| Insert (end)        | O(1) amortized |
| Insert (middle)     | O(n)           |
| Delete              | O(n)           |

---

## 🧩 Key Concepts

- Dynamic resizing
- Index-based access
- Shifting elements after insert/delete
- Using built-in methods (`add()`, `remove()`, `get()`)

---

## ⚠️ Common Mistakes

- Confusing ArrayList with arrays
- Ignoring shifting cost (O(n))
- Index out of bounds errors
- Modifying list while iterating incorrectly

---

## 🔁 Array vs ArrayList

| Feature      | Array        | ArrayList     |
|-------------|-------------|--------------|
| Size        | Fixed       | Dynamic      |
| Performance | Faster      | Slightly slower |
| Flexibility | Low         | High         |
