# Two Pointers

This folder contains problems based on the two-pointer technique.

## 🧠 Concept

Two pointers are used to reduce time complexity by avoiding nested loops.  
Common patterns include:
- Opposite direction pointers
- Same direction pointers
- Sliding window techniques

## 📌 Problems Implemented

- Two Sum II
- Remove Element
- Remove Duplicates (Basic)
- Pair with Difference
- Count Pairs Less Than Target
- Merge Two Sorted Arrays

## ⚙️ Key Techniques Used

- Left & Right pointer movement
- Expanding and shrinking window
- Efficient pair counting
- In-place array modification

## 🎯 Goal

To master array traversal optimization and build a strong foundation for advanced problems like 3Sum and sliding window.
